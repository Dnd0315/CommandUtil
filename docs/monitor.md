# Monitor

[← Index](../README.md)

- `iostat` → activité des disques (lectures/écritures) ; `iostat 2` = toutes les 2 s
- `pidstat` → consommation CPU par processus ; `pidstat -d` = disque
- `vmstat 2` → mémoire, CPU, I/O toutes les 2 s

Pour `top` (processus en direct) : voir [Boot, processus](boot-processus.md).
